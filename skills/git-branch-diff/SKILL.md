# Git 分支差异报告生成器

## 概述

基于 `git diff`（三点语法）生成特性分支相对于基础分支的完整差异报告。自动执行 `git fetch` 确保远程数据最新，输出分类文件清单和详细 diff 内容。

## 工作流程

### 1. 确认参数

从用户输入中提取两个分支名：
- **基础分支**：作为对比基准的分支（如 `main`、`master`、`develop`）
- **特性分支**：需要查看改动的分支

如果用户只提供了一个分支，默认基础分支为 `main`。

### 2. 运行脚本

执行脚本生成报告：

```bash
python3 scripts/gen_diff.py <基础分支> <特性分支>
```

脚本的工作目录必须是 git 仓库根目录或其子目录。

### 3. 输出说明

脚本会在当前工作目录（调用脚本时所处的目录）生成 `diff_report.md`，包含：

- **分支信息**：基础分支、特性分支的 commit hash，merge base 信息
- **文件分类清单**：新增 / 删除 / 修改的文件列表
- **变更统计**：每个文件的增删行数
- **详细差异**：完整的 unified diff 内容

### 4. 向用户汇报结果

向用户简要报告：
- 变更文件数量（新增 / 删除 / 修改）
- 报告文件路径
- 如果变更较少，可以直接摘要关键改动点

## 注意事项

- 脚本会自动执行 `git fetch --all`，确保远程分支数据可用
- 使用三点语法（`base...feature`），只显示特性分支独有的改动，不包含基础分支上别人的改动
- 如果特性分支曾多次 merge 基础分支，merge base 会自动定位到最新的公共 commit，结果仍然准确
- 脚本不需要两个分支的文件 checkout 到磁盘上，git 比较的是 commit 快照
